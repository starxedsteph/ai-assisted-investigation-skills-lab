# PyPI Investigation

This exercise is open-ended. Start with about a month of PyPI data, then choose
what you want to investigate and follow the leads that interest you.

## 1. Get the data

Ask your agent to use BigQuery to retrieve about a month of PyPI publication
metadata. October 2026 is a starting point, but you can choose another month.
Use the [public PyPI metadata dataset](https://docs.pypi.org/api/bigquery/).

If BigQuery isn't set up, follow the instructions in
[ai-assisted-investigation-skills](https://github.com/starxedsteph/ai-assisted-investigation-skills).

## 2. Explore

Choose your own questions and ask your agent to investigate. Follow up on
interesting results, request additional queries, and decide how you want to
present what you find.

Watch which skills the agent uses, including `safe-data-ingestion` and, when
relevant, `campaign-identification` or `investigation-package-impersonation`.
Work with metadata only; don't download, install, or run the packages.
